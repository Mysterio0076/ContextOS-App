# ContextOS

Your personal project memory workspace.

ContextOS is a local-first application for organizing projects, notes, decisions, and tasks.

## Features

- Project management
- Notes and decisions
- Task tracking
- Global search
- Local browser storage
- JSON backup export

## Tech Stack

- React
- Vite
- JavaScript
- CSS

Under active development.
